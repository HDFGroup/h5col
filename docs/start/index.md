# Getting started

These pages take you from "what is this?" to a working table. If you already
use a columnar format, begin with the first page — it explains what H5Col adds
and, just as honestly, what it does not try to replace. The installation page
covers the supported ways to install the package today, and the quickstart
builds, queries, and reopens a small table end to end.
